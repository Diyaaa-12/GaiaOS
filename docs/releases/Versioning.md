# GaiaOS Versioning Strategy

This document details the versioning strategy, historical tag evolution, and future release roadmap for GaiaOS.

## Historical Releases

- **v0.2.0** — Phase 2: Multi-Agent Reasoning Core, LangGraph Integration & Literature RAG
- **v0.3.0** — Phase 3: Durable Execution, JWT/API Key Auth & Evaluation Suite

These historical tags were established during earlier phases of development before the current release series strategy was formalized. They are intentionally preserved unchanged as an essential part of the repository's engineering and commit history.

## Current Release Strategy

Beginning with Phase 4, GaiaOS adopted a structured release strategy aligned with major engineering milestones, governance readiness, and open-source release series.

The **v4.x Open Source Readiness** release series is structured as:

- **v4.0.0** — Phase 4 Complete (Production Monitoring, Backup & Disaster Recovery, Admin UI, OpenAPI Spec Publishing)
- **v4.1.0** — Repository Governance (Apache License 2.0, Security Policy, Code of Conduct, CODEOWNERS, Issue & PR Templates)
- **v4.2.0** — Community Health (Community Guidelines, Contributor Support Infrastructure)
- **v4.3.0** — Contributor Experience (Developer Tooling, Environment Ergonomics, Onboarding Automation)
- **v4.4.0** — Engineering Cleanup (Deprecation Resolution, Codebase Hygiene, Audit Maintenance)
- **v4.5.0** — Open Source Release Candidate (Final Pre-release Verification & Security Audit)

## Future Releases

- **v5.0.0** — Phase 5 (Autonomous Planetary Intelligence & Multi-Region Agent Scaling)

Subsequent major and minor releases will follow Semantic Versioning (SemVer 2.0.0) principles (`MAJOR.MINOR.PATCH`) while maintaining full compatibility with the project's milestone-based engineering workflow.
